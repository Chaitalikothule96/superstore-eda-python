📊 Superstore Data Analysis (Python)

🔹 Problem Statement
Analyze retail superstore dataset to identify sales trends, profit patterns, and key business insights.

🔹 Tools Used
Python, Pandas, Matplotlib, Seaborn

🔹 Data Cleaning

Removed unnecessary columns (Postal Code)
Converted date columns to proper datetime format
Removed duplicate records
Checked and handled missing values

🔹 Analysis Performed

Category, Segment, and State distribution
Sales vs Profit relationship
Discount impact on Profit
Correlation analysis between numerical variables
Outlier detection using boxplots

🔹 Key Insights

High discounts negatively impact profit
Certain categories generate more sales but lower profit
Strong correlation observed between sales and profit
Outliers present in sales and profit data
